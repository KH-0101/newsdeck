# newsdeck

登録したニュースサイトやブログの RSS を毎朝自動で集め、日付ごとの1ページにまとめて GitHub Pages で読む、個人用のニュース集約ツールです。

- 載せるのはタイトル、リンク、抜粋（最大120字）、取得元だけです。記事の本文は転載しません。
- PR・広告記事は除外し、件数だけを折りたたんで表示します。
- 仕様は [SPEC.md](SPEC.md)、作業計画は [TASKS.md](TASKS.md) にあります。

## ページの見方

GitHub Pages の URL（`https://<ユーザー名>.github.io/newsdeck/`）を開きます。

| ページ | 内容 |
|---|---|
| `index.html` | 今日のページ。毎朝 6:00 JST ごろに更新されます（GitHub の混み具合で数十分遅れることがあります） |
| `YYYY-MM-DD.html` | 日付ごとのページ。30日分を残します |
| `archive.html` | 日付の一覧と、各日の新着件数 |

- 「新着」は、**その日に初めて取得した記事**です。公開日時ではありません。
- 情報源ごとに「新着なし」「⚠ 取得失敗（理由）」を表示します。失敗が続く情報源は URL を確かめてください。
- 「PR除外 n件」を開くと、除外した記事と、一致したキーワードが見られます。普通の記事が混ざっていたら、キーワードを見直してください。
- 時刻は日本時間です。ページの日付と違う日の記事には `MM/DD` が付きます。

## 情報源の追加・削除

情報源は `feeds.json` を手で編集して登録します。GitHub の画面で直接編集してコミットしても、手元で編集して push しても構いません。

### 追加する

1. 公式の RSS / Atom の URL を確かめます。集約サービス（Googleニュースなど）やまとめサイトの RSS は使いません（SPEC 3.1）。
2. `feeds.json` の `feeds` に1件足します。

   ```json
   { "id": "example-blog", "name": "Example ブログ", "url": "https://example.com/feed.xml", "category": "技術", "lang": "ja", "trial": true, "addedAt": "2026-12-01", "excludeKeywords": [] }
   ```

   | 項目 | 書き方 |
   |---|---|
   | `id` | 英小文字・数字・ハイフン。**あとで変えない**（新着判定のキーです） |
   | `category` | `一般`、`国際`、`技術`、`セキュリティ` のどれか。ページではこの順に並びます |
   | `lang` | `ja` か `en` など |
   | `trial` | 新しく足すときは `true`（お試し期間） |
   | `addedAt` | 追加した日（YYYY-MM-DD） |
   | `excludeKeywords` | この情報源だけで使う除外キーワード（無ければ `[]`） |

3. 手元で確かめるなら `npm test` と `npm run build` を実行します。`feeds.json` に誤りがあると、何が悪いかを表示して止まります。
4. コミットして push します。次の朝（または手動実行）から取得されます。

### お試し期間

- `trial: true` の情報源には「お試し」と表示し、直近14日の1日あたりの平均件数と PR除外の件数を出します。
- 2週間たったら、残すか外すかを決めます。残すなら `trial` を `false` にします。

### 削除する

`feeds.json` から消します。過去のページには「（登録解除）」として残り、30日で消えます。

### 除外キーワード

全体共通のキーワードは `feeds.json` の先頭の `excludeKeywords` にあります。

- 英字だけのキーワード（`PR`、`AD`、`Sponsored`）は、大文字・小文字を区別せず、単語として一致したときだけ除外します（`ADHD`、`PRESS` は除外しません）。
- それ以外は部分一致です。`提供` のように普通のニュースにも出る言葉は避け、`提供：` や `【広告】` のように PR 表記の形で書きます（SPEC の D-23）。

## 手動で更新する

GitHub のリポジトリの **Actions** タブ → 左の「毎朝の更新」→ **Run workflow** を押します。同じ日に何度実行しても、追加分だけが追記されます。

## 手元で動かす

```sh
npm install
npm test        # テスト（ネットワークを使わない）
npm run build   # フィードを取得して data/ と public/ を作る
```

`public/index.html` をブラウザで開くと、今日のページが見られます。手元で作った `data/` はコミットしないでください（Actions が毎朝作ります）。

## APIキーについて

このリポジトリは公開しています。

- APIキーやトークンは**コミットしません**。必要になったときは GitHub の Actions Secrets にだけ置きます。
- 生成した HTML やブラウザで動く JavaScript には、キーを入れません。
- 今は APIキーを使う処理はありません（AI要約は保留中。SPEC 10）。
