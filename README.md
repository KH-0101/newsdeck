# newsdeck

登録したニュースサイトやブログの RSS を毎朝自動で集め、日付ごとの1ページにまとめて GitHub Pages で読む、個人用のニュース集約ツールです。

- 載せるのはタイトル、リンク、抜粋（最大120字）、取得元だけです。記事の本文は転載しません。
- PR・広告記事は除外し、件数だけを折りたたんで表示します。
- 仕様は [SPEC.md](SPEC.md)、作業計画は [TASKS.md](TASKS.md) にあります。

## 使い方（ローカル）

```sh
npm install
npm test        # テスト（ネットワークを使わない）
npm run build   # フィードを取得して data/ と public/ を作る
```

`public/index.html` をブラウザで開くと、今日のページが見られます。

## 情報源の追加・削除

`feeds.json` を手で編集します（詳しくは T5-1 で追記します）。

## APIキーについて

このリポジトリは公開しています。APIキーやトークンはコミットせず、必要になったときは GitHub の Actions Secrets にだけ置きます。
